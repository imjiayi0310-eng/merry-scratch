# Merry Scratch 🎄

手绘圣诞树刮刮卡 PWA 应用——全屏黑色画面，手指涂抹刮开，揭示随机圣诞树。

> **本产品由我作为产品负责人，借助 Claude Code 从 0 到 1 独立完成**（需求定义、原型设计、前端开发、部署、数据埋点）。

## 🎯 在线体验

- **CloudBase 线上版（推荐）**：https://hmyjh12-d8g8lf2oz5b5a1de8-1443654105.tcloudbaseapp.com
- GitHub Pages（旧版）：https://imjiayi0310-eng.github.io/merry-scratch/

## ✨ 核心功能

- 手绘圣诞树刮刮卡：手指涂抹刮开，随机揭示圣诞树
- 全屏黑色画面 + 音效
- PWA 支持（可离线使用）
- 数据埋点：链接生成数、刮奖完成率、裂变率

## 🛠 技术栈

- 前端：Vanilla JS + Canvas + HTML/CSS
- 后端：腾讯云 CloudBase
- PWA：Service Worker + Manifest
