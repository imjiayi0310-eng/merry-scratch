# 设计规范 — Merry Scratch

## 色彩

| 用途 | 色值 |
|------|------|
| 背景（夜空） | `#020208` 渐变至 `#0d1020` |
| 引导光晕 | 粉金渐变 `#ffb8c6` → `#ffd700` |
| 火花粒子 | 金色 `#ffd700` / `#ffaa44` |
| 粉色柔光 | `#ffb8c6` / `#ffd1dc` |
| 雪花 | 白色 `#ffffff` + 少量粉色 `#ffd1dc` |
| 聚光灯暗角 | `#020208` 渐变透明 |
| 重抽按钮 | 半透明白底 + 白边框 |

## 字体
- 系统字体栈：`-apple-system, 'PingFang SC', 'Hiragino Sans GB', sans-serif`
- 引导文字大小：`clamp(16px, 4vw, 22px)`
- 字间距：3px

## 动画
- 光晕呼吸：2.5s 周期
- 打字机速度：80ms/字
- 雪花飘落：20-50px/s
- 灯光闪烁：1.2-4.7s 随机周期

## 交互
- 触摸即刮，无需教程
- 首次触摸引导光晕 → 爆炸粒子过渡
- 揭示后右下角小图标可重抽
- 全屏无边框无滚动
