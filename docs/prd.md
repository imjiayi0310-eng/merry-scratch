# Merry Scratch — 产品需求文档（PRD）

> 版本：v1.0 | 日期：2026-06-16 | 状态：已确认

---

## 一、产品概述

### 1.1 一句话定位

**Merry Scratch** 是一款温暖治愈的节日刮刮乐社交工具。朋友之间互赠定制惊喜——赠送者设奖品、生成链接，被赠者刮开圣诞树和银色圆片，发现属于自己的小礼物。

### 1.2 产品愿景

从圣诞起步，逐步覆盖新年、情人节、生日等送礼场景，成为中文互联网上"传递小心意"的首选轻量工具。

### 1.3 核心价值

| 角色 | 获得 |
|------|------|
| 赠送者 | 低成本、高仪式感地传递心意；看到对方刮出惊喜的反馈 |
| 被赠者 | 像拆礼物一样的惊喜体验；刮开过程有参与感和期待感 |
| 平台 | 裂变传播——被赠者刮完后自动引导成为新赠送者 |

## 二、市场与用户

### 2.1 市场背景

- 中国节日送礼市场巨大，但"轻量心意表达"工具空白
- 微信红包解决了"钱"的问题，但没解决"惊喜感"
- 现有的电子贺卡、H5 小游戏缺乏互动深度和个性定制

### 2.2 竞品分析

| 类型 | 代表 | 与 Merry Scratch 的区别 |
|------|------|------------------------|
| 微信红包 | 微信原生 | 只有金额，没有惊喜感和互动过程 |
| H5 贺卡 | 易企秀等 | 单向展示，不涉及刮开交互和奖品机制 |
| 电商刮刮卡 | 淘宝/京东活动 | 商业促销导向，非朋友社交场景 |
| 盲盒类 | 泡泡玛特小程序 | 实物商品，非纯社交体验 |

**结论**：Merry Scratch 占据了一个差异化定位——轻量、社交、可定制、真交互的"小心意传递工具"。无直接竞品。

### 2.3 用户画像

**主要用户：赠送者**
- 年龄：18-30 岁
- 性别：女性为主
- 场景：想给闺蜜/伴侣一份小惊喜，但不想太隆重
- 动机：低成本表达心意，有仪式感但不沉重
- 行为：用微信分享链接，一次设置可发给多人

**主要用户：被赠者**
- 年龄/性别：与赠送者相近
- 场景：收到链接，在手机上刮开惊喜
- 期望：有趣、好看、有期待感
- 行为：刮完后有动力转发给更多人

## 四、核心流程

### 4.1 赠送者流程

```
打开链接 → 首页点「🎅 为朋友准备惊喜」
  ↓
步骤1：选择圣诞树（4选1，缩略图平铺）
  ↓
步骤2：配置10个圆片
  · 点击圆片 → 设为有奖/无奖
  · 有奖圆片填写奖品（限15字）
  · 快捷选项：香草冰淇淋/圣诞大餐/仙女棒/一条围巾/立刻见面吧
  · 自定义：输入后回车确认
  · 可重复设相同奖品
  ↓
步骤3：设置每人可刮次数（1-10）
  ↓
生成专属链接 → 复制分享到微信
```

### 4.2 被赠者流程

```
打开链接 → 首页点「🎁 我有刮奖链接」
  ↓
Merry Scratch 标题页 + 真实加载进度条
  ↓
18s 开场视频（全屏、仅一次、可跳过）
  ↓
刮圣诞树（9:16 全屏树图）
  · 引导光晕 + 打字机提示
  · 手指涂抹刮开黑色涂层
  · 刮到 40% → 整树呈现 + 音乐
  ↓
树上出现 10 个银色圆片（1+2+3+4 金字塔排列）
  · 提示：刮开银色圆片，看看有什么惊喜
  · 剩余次数显示
  · 点击选中 → 手指刮开涂层
  · 每次只能刮 1 个
    ↓                      ↓
  中奖 → 弹窗 + 惊喜音效    未中 → 底片显示「圣诞快乐 🎄」
  ↓
全部刮完 → 总结弹窗（列出所有奖品）
  ↓
底部：「✨ 也为朋友准备一份惊喜吧」→ 跳转赠送者设置页
```

## 六、交互细节

### 6.1 刮圣诞树

- 引导：中央呼吸光晕 + 打字机「用指尖轻轻涂抹」→「你会发现…🎄」
- 画笔：70px（手机）/ 45px（桌面）
- 进度采样：每 0.4s，缩略图法
- 阈值：40%
- 揭示：1s 淡出 + 铃声 + 雪花

### 6.2 刮圆片

- 排列：树上 1+2+3+4 金字塔
- 大小：~12% 屏宽（约 45px）
- 交互：点击选中（金色光环）→ 手指刮开涂层
- 防误触：仅激活被点击的圆片
- 阈值：50% 涂层刮掉
- 中奖弹窗：emoji +「🎉 恭喜你获得了 XXX」
- 空圆片：底片圆圈 +「圣诞快乐 🎄」

### 6.3 视觉风格

- 主色调：深邃黑 + 暖金 + 柔粉
- 字体：系统字体，圆润温暖
- 文案调性：温暖治愈——软萌、温柔、像朋友在耳边说话
- 关键 UI：半透明毛玻璃 + 圆角 + 微光晕

## 七、数据规则

| 规则 | 说明 |
|------|------|
| 奖品可重复 | 多个圆片可设相同奖品 |
| 圆片可为空 | 0-10 个有奖，赠送者自由决定 |
| 刮片顺序 | 任意顺序，无限制 |
| 每人次数 | 每个被赠者独立计数 |
| 中断恢复 | 进度存 CloudBase，重开继续 |
| 赠送者可见 | 仅在全部刮完后可看结果 |
| 链接永久有效 | 不过期 |
| 链接不可修改 | 生成后固定 |
| 匿名身份 | 被赠者自动分配匿名 ID |

## 八、边界情况

| 场景 | 处理 |
|------|------|
| 视频加载失败 | 显示跳过 → 直接进游戏 |
| 链接 ID 无效 | 错误提示 |
| 已刮完所有次数 | 显示总结 + CT |
| 同设备双标签 | 检测并提示 |
| 断网 | 保留已填内容 + 重试提示 |
| 清除浏览器数据 | 新匿名 ID，重头开始 |
| 被赠者转发链接 | 新用户，独立进度 |
| 奖品超 15 字 | 输入时截断 |

## 九、成功指标

| 指标 | 定义 |
|------|------|
| 链接生成数 | 赠送者创建了多少条专属链接 |
| 被赠者数 | 有多少独立用户打开了链接 |
| 刮奖完成率 | 打开链接的人中，刮完所有圆片的比例 |
| 裂变率 | 刮完后点击「也为朋友准备」的比例 |
| 人均分享 | 每个赠送者平均发给了几个人 |
