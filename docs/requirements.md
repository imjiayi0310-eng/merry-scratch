# 项目需求文档 — Merry Scratch

## 项目概述
手绘圣诞树刮刮卡 PWA 应用。全屏黑色画面，用户手指涂抹刮开 → 露出随机圣诞树 + 飘雪。

## 核心功能

| 功能 | 描述 | 状态 |
|------|------|------|
| 刮开交互 | 手指/鼠标涂抹黑色覆盖层，Canvas destination-out | ✅ |
| 随机圣诞树 | 6 种手绘圣诞树，首次随机后永久绑定 | ✅ |
| 引导动画 | 中心呼吸光晕 + 打字机文字 | ✅ |
| 揭示判断 | 刮开 40% 自动揭示 | ✅ |
| 音效 | 风雪刮擦声（循环）+ 钢琴铃声 | ✅ |
| 重新抽取 | 右下角图标按钮，无刷新重置 | ✅ |
| PWA | manifest.json + sw.js + 主屏幕图标 | ✅ |

## 非功能需求
- 全屏沉浸，无浏览器 UI（添加到主屏幕后）
- 触控优先，桌面鼠标兼容
- 加载速度 < 3 秒（目标 < 500KB 首屏）
- iOS Safari 兼容，Android Chrome 兼容
