# Merry Scratch 2.0 — 完整计划

> 最后更新：2026-06-15 | 状态：需求已确认，待开工

---

## 一、概念

单人刮刮乐升级为「赠送者设置 → 生成专属链接 → 被赠送者刮奖 → 推广裂变」的双向社交体验。

平台：腾讯云 CloudBase + Web PWA（国内）

---

## 二、URL 结构

| 路由 | 用途 |
|------|------|
| `/` | 首页 |
| `/create` | 赠送者设置（永远全新空白） |
| `/play?id=xxx` | 被赠送者游戏 |

核心规则：`/create` 永远新建。链接生成后不可修改。被赠送者无法访问设置。

---

## 三、交互流程

### 首页 `/`

两个按钮：「🎁 我有刮奖链接」「🎅 为朋友准备惊喜」

### 被赠送者（/play?id=xxx）

1. 18s 全屏视频（仅一次，无跳过，加载进度条，失败可跳过）
2. 自动过渡 → 9:16 树图全屏刮刮乐
3. 刮到 40% → 树完整呈现 + 铃声
4. 10 个银色圆片（1+2+3+4 金字塔，均匀分布在树身上）
5. 底部提示 + 剩余次数计数
6. 点击选中圆片（金光边缘）→ 仅该圆片可刮
7. 中奖：🎉 弹窗 + emoji + 惊喜音效
8. 未中：「圣诞快乐 🎄」
9. 全部刮完 → 「✨ 也为朋友准备一份惊喜吧」→ 跳 /create

### 赠送者（/create）

1. 不看视频，直接进设置
2. 选树（4 选 1 缩略图）
3. 点击圆片配置奖品（有奖/无奖）
4. 快捷选项：香草冰淇淋 / 圣诞大餐 / 仙女棒 / 一条围巾 / 立刻见面吧 + 自定义（限 15 字）
5. 设置每人可刮次数（1-10）
6. 生成链接 → Firestore → 复制分享
7. 被赠者全刮完后可查看结果清单

## 四、决策汇总

| 类别 | 决策 |
|------|------|
| 界面 | 代码第一版 → 审阅迭代 |
| 圆片 | Canvas 金属涂层，12% 屏宽，点击选中 |
| 视频 | 18s 全屏，压缩 ≤4MB，仅一次 |
| 树图 | 9:16 全屏 PNG，4 张 |
| 插图 | Emoji |
| 身份 | 匿名 ID |
| 链接 | 永久有效，不可修改 |
| 次数 | 每人 X 次 |
| 字数 | 15 字限制 |
| 音效 | 2-3 秒，用户提供 |

---

## 五、全流程提示词

**视频页**：加载「✨ 正在准备惊喜… X%」失败「视频加载失败，点此跳过」

**刮树页**：「用指尖轻轻涂抹」→「你会发现…🎄」

**刮圆片页**：底部「✨ 刮开银色圆片，看看有什么惊喜」+「还可以刮 X 次」中奖「🎉 恭喜你获得了 _____」未中「圣诞快乐 🎄」完成「✨ 也为朋友准备一份惊喜吧」

**设置页**：「为朋友准备一份圣诞惊喜」「🎄 选择圣诞树」「🎁 点击圆片设置奖品」「每人可刮 X 次」「✨ 生成专属链接」「🎄 链接已生成！发给朋友吧」

---

## 六、边界情况

| 问题 | 处理 |
|------|------|
| 视频加载失败 | 跳过进游戏 |
| 链接无效 | 错误提示 |
| 已刮完 | 显示结果 |
| 刮到一半关浏览器 | Firestore 存状态 |
| 断网 | 错误提示 + 保留已填 |
| 同设备双标签 | 检测并提示 |

---

## 七、数据模型（Firestore）

```
links/{linkId}       — 奖品配置 + 树 ID + 次数
receivers/           — 每个被赠者刮奖进度
```
